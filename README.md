# PDE Study OS

Static study app for the Google Cloud Professional Data Engineer exam.

## Open it

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 4173
```

Then visit http://localhost:4173

Progress is stored in localStorage (`pde-study-os-v1`). No account, no backend.

## What is inside

Five official domains (22 / 25 / 20 / 15 / 18), topic readers, service atlas, decision matrices, flashcards, domain quizzes, scenario dojo, five labs, timed mock, 6-week path, XP / ranks / badges / daily quest.
